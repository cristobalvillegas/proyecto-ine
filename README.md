## Introducción

En este proyecto se analizan datos recopilados por el Instituto Nacional de Estadística (INE) de Chile a través de la Encuesta Nacional de Empleo (ENE), específicamente las tasas de ocupación y desocupación. De esta manera, se observa el cambio de ambas proporciones a través del año 2025 y se modelan ambas variables en cada contexto y se aplica estadística inferencial (pruebas de hipótesis, intervalos de confianza y tamaños de efecto), dado el supuesto de una metodología de recolección de datos de muestreo aleatorio simple, para comprobar si existe dependencia entre el mes en el que se realiza la encuesta con dichas variables para luego realizar pruebas de comparación de proporciones para observar los cambios significativos durante este período de tiempo. 

## Librerías Utilizadas

Para el desarrollo de este proyecto se utilizaron las siguientes librerías en Python:

1. Pandas: Visualización y manipulación de datos (requiere instalación)
2. Numpy: Cálculos númericos (requiere instalación)
3. Scipy: Cálculos estadísticos y pruebas de hipótesis (requiere instalación)
4. Matplotlib: Creación de gráficos (requiere instalación)
5. Seaborn: Creación de gráficos para estadística (requiere instalación)
6. Statsmodels: Cálculos estadísticos y pruebas de hipótesis (requiere instalación)
